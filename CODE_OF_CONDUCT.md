# Code of Conduct

This project adopts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) (v2.1), condensed:

**Expected:** welcoming, precise, evidence-based communication · critique the work, not the person · assume good faith and verify claims · help newcomers land their first PR · content warnings for security discussions.

**Not tolerated:** harassment, discrimination, personal attacks · publishing others' private data · bad-faith issue spam or astroturfing · pushing promotional content or pay-to-play endorsements as "rules".

**Enforcement:** maintainers may warn, edit/lock, or remove content and ban contributors who violate this. Report concerns via GitHub's reporting tools or the maintainer's profile contact. Reports are confidential.

Violations exist in the real world; so does accountability. Be excellent to each other.
